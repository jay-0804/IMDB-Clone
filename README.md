# IMDb Clone

An IMDb-inspired movie discovery web application built using React and TMDB API. Users can browse trending movies, search for titles, view ratings, and explore detailed movie information through a clean and responsive interface.

## Features

- Browse trending and popular movies
- Search movies by title
- View movie ratings and details
- Responsive UI
- Real-time movie data using TMDB API

## Tech Stack

- React
- JavaScript
- CSS
- Vite
- TMDB API

## Installation

1. Clone the repository

git clone https://github.com/your-username/IMDB-Clone.git

2. Navigate into the project folder

cd IMDB-Clone

3. Install dependencies

npm install

4. Create a `.env` file and add your TMDB API key

VITE_TMDB_API_KEY=your_api_key

5. Start the development server

npm run dev
